# 最终形象与动画说明

使用内置 imagegen 生成和定向编辑；参考图片保存在 `assets/maltese-retriever/references/`。

## 最终提示约束
保留 moonlab_studio 的线条小狗原始 IP 形象，不重新设计。小鸡毛（金毛）在左，小白（马尔济斯）在右，两只开心地靠在一起。保留小鸡毛浅金色身体、珊瑚色项圈，以及小白的白色绒毛轮廓。小鸡毛尾巴上下摆动。三颗粉色爱心按从上到下的顺序逐个出现，帧序为 0、1、2、3、2、0 颗，随后循环。

用户补充的左看参考是 `user-left-look.png`：左看时小鸡毛保留宽圆头型、短小且内收的鼻口、小 W 形笑脸、自然垂耳；用轻微转头和面部偏移表达左看，避免拉长的尖嘴。该约束用于整组左侧视线和向左移动动画。

## 图集与验证
应用自带 Hatch Pet 工具处理实际生成的像素，完成提取、共享基线配准、图集合成、一次最终边缘清理和校验。192×208 像素单元，8列11行，v2 格式1536×2288。九种标准状态和十六个视线方向分别生成并检查。爱心为用户明确要求，优先于技能默认的无独立特效建议。

最终检查记录见 `animation/pet-run/qa/`。生成过程不使用图像 API 密钥。
