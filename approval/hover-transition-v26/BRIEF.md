# 待机与 hover 衔接

用户指出待机切到 hover 不连贯。实测当前待机首帧外接范围为 `(7,83,185,195)`，v25 hover 首帧为 `(13,83,179,199)`：不仅从依偎变为正坐收爪，宽度、五官相对姿态和落脚基准也会突然变化。

本稿只重新组合已审批像素：hover 首尾帧直接使用真实待机首帧，使状态边界的角色姿态完全相同；中间三帧继续使用 v25 的上升、最高点和下降，整体上移 4 像素，与待机底边 195 对齐。立耳、五官间距、细鼻线、身体及耳根描边保留；没有重画或缩放角色。

原生 hover 仍为五帧，时序 `140ms ×4 +280ms`。因此本候选将两端正坐收爪姿态改为待机端点，不增加原生帧，不通过减慢 GIF 掩盖衔接。完整预览按真实待机一轮 → hover 一轮 → 待机一轮播放；状态切换时爱心跟随相应状态的原生效果，不额外混合效果。

`transition-comparison-2x.gif` 左侧为 v25 衔接、右侧为本稿；`idle-hover-idle-2x.gif` 为完整衔接展示；`jumping.gif` 为原生五帧候选。记录见 status.json。审批前不更新安装包、本机和云端。
