# 以待机为基准统一颜色和线宽

用户要求：各动画以待机为基准统一颜色、线条粗细；清理旧候选与失败稿。用户另行明确允许使用 Python 直接处理原图。

采用原始图集逐像素校准：待机整行不变；从待机采样黑色、奶黄色、白色、项圈红和爱心粉；其他行按原颜色混合覆盖率映射到相同色板。按描边骨架统计微调墨色覆盖范围，保留透明度、帧布局、动作、原生时序；保护独立的小眼睛、鼻子和嘴巴。左行走取处理后右行走各帧的精确水平镜像。

`baseline.webp` 为变更前当前图集；`before-after.png` 每行左三格为原图、右三格为调整后。完整参数与像素校验记录见 `style-report.json`。线宽是栅格骨架统计的估计值，保留原手绘的局部变化。

先尝试了内置 image_gen，未采用：结果出现光晕和局部细节变化。其提示词为：仅按第一行待机统一全图颜色及黑色描边，保留全部姿势、表情、轮廓、单元位置、尺寸、帧序、透明背景，左右行走互为镜像，待机不变。未将该失败图集集成或打包。最终采用用户授权的 Python 处理，无生成图替换动作。

旧候选和失败稿从 approval、drafts 中移除前，全部文件已逐一验证 SHA256 与恢复归档相同。清理清单见 `../cleanup-20261021.json`，恢复归档位于 `../../build/obsolete-animation-candidates-20261021.zip`。原始用户参考图额外保存到 assets/maltese-retriever/references。
