# 等待输入与检查结果：拟人动作审批稿

依据：工作区 `线条小狗-design.md` 和 `AGENTS.md`。仅制作 waiting、review 的六帧候选 GIF，用户审批前不集成、不打包、不安装、不更新云端。

身份与风格以当前统一色板的待机首帧为准：小鸡毛左、小白右，短圆身体、小五官、手绘粗黑线、奶黄与白色平涂。两只都采用拟人坐姿，短手臂由上身伸出，圆润的臀部和下肢保持连续，不用落地前爪或四足动物姿态。

- 等待输入：原位 → 双手收拢 → 胸前轻合手、期待侧头 → 小幅换侧或开心眨眼 → 胸前轻轻摊手 → 回到原位。
- 检查结果：原位 → 短手托腮 → 微微侧头观察 → 满意点头 → 胸前轻轻展开手 → 回到原位。

不新增道具、文字、配饰或爱心；小鸡毛尾巴保留轻微上下摆动。整行动画使用共同缩放与定位基准，身体以待机 178×112 像素、底边 195 校准，不逐帧强制拉伸尺寸。

使用内置 image_gen 分别生成两条六帧动作源图，再使用透明抠图、统一定位和预览管线制作 GIF。完整提示词：[等待输入](waiting-prompt.txt)、[检查结果](review-prompt.txt)、[手部颜色与绒毛轮廓修正](correction-prompt.txt)。
